Getting help with ZoomLens

Last updated October 29, 2026

Contact

Report a problem or ask a question by opening an issue on GitHub. Please don't include screenshots of anyone's shared screen, or anything private from a meeting.

Common problems

The panel says "Not started", and there's no Start button

Your Zoom client may be older than 6.5.5, which the Start button needs. Update Zoom, or ask the host to start ZoomLens.

I pressed Start and nothing happened

If you're not the host, Zoom asks the host to allow ZoomLens first. If the host declined, or their settings don't allow apps to access meeting content, it can't start. The panel says so after about 30 seconds, and you can try again.

"There is no screen to look at yet"

Nobody is sharing their screen right now. Ask again once someone shares.

"Limit reached"

Each person can ask once every few seconds and a set number of times a day, which keeps ZoomLens affordable to run. The panel says how long to wait.

"This panel couldn't be verified"

Close ZoomLens and open it again from the meeting's Apps menu. This happens after the ZoomLens server restarts.

An answer is wrong

Answers come from an AI reading a picture of the screen, so small text or a busy chart can be misread. Ask a follow-up, or check what's actually on screen.
